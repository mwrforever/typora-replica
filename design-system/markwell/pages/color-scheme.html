一、设计理念

上一版（teal 主色 + orange 强调）被整体否决。v2 转向「纸墨」： 写作工具的本质是一张纸、一支笔、一瓶墨，配色应该安静、克制、有书卷气。

正文使用墨蓝链接（7.9:1），行内代码用 枣红墨色，强调色只有一种——墨蓝，不再有第二撞色。

1.1 为什么 v1 显得「丑」

  • teal + orange 是模板级撞色组合，缺少辨识度
  • 纯白纸面 + 冷灰边框：平、无层次、像未完成品
  • 暗色用中性灰 #1e1e1e，没有任何色相倾向，死气沉沉

1.2 v2 四项决策

  1. 去纯白/纯灰：亮色暖纸白，暗色暖炭，两态同气质
  2. 单一墨蓝强调（暗态映射雾蓝），错误红仅作例外
  3. 纸面与外壳分层：外壳暖灰、纸面近白，暗色外壳微亮于画布
  4. 正文对比度全 ≥ 4.5:1，控件边框 ≥ 3:1，脚本验证

写作时眼睛停留最久的是纸面。纸面稳，界面才高级。

配色设计 v2「纸墨 Ink & Paper」

取代 2026-08-15 被否决的 v1（teal + orange）。亮/暗两态同一气质，正文对比度全部达标。

v1 否决原因（勿再犯）

  • teal 主色 + orange 强调：模板级撞色，无辨识度
  • 纯白纸面 + slate 冷灰边框：平、无层次
  • 暗色中性灰 #1e1e1e：无色相倾向，死气沉沉

v2 四项决策

  • 去纯白/纯灰：亮色暖纸白 + 暖墨，暗色暖炭 + 暖白
  • 单一墨蓝强调（暗态映射雾蓝），错误红仅例外
  • 纸面与外壳分层：亮色外壳暖灰、纸面近白；暗色外壳微亮
  • 对比度脚本验证：正文 ≥4.5:1、控件边框 ≥3:1（22 项全过）
