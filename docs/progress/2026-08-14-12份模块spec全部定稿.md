## 4. 全局约定 (Locked Conventions)

- **spec 驱动流程**：brainstorm → spec → writing-plans → TDD → 执行 → review（superpowers 技能）；12 份 spec 已定稿，实现以各模块 spec 第 7 节 AC 为完成定义，改 spec 必须先经用户同意
- **clean-room 边界**：调研/实现仅限 Typora 官方公开文档 + 用户实操观察 + 开源生态与公开标准；禁止解包/提取 Typora 闭源代码；内置主题原创编写（Typora 主题仅风格参考）
- **注释/编码规范**：全部注释/日志/文档中文；源码 UTF-8 无 BOM、LF 行尾；核心功能单测 100%、非核心 ≥80%；死代码零容忍（本次改动产生的废弃代码同次提交清理）
- **CI 结构**：PR → Quality Gate（ESLint/Prettier/vue-tsc/Vitest + rustfmt/clippy/cargo test + gitleaks/npm audit/cargo-deny）→ Build Verification（Windows 构建 + CI 冒烟 + 产物）；CI 冒烟为确定性验证（e2e/smoke-ci.mjs），**不得**改回依赖 CDP 调试端口的方案（WebView2 150 回归，见 e2e/README.md 恢复指引）
- **pre-commit**：markdown 需过 prettier（提交前 `npx prettier --write` 目标文件）；失败时用 prettier 修复后重提
- **Git Bash 环境坑**（详见项目记忆 windows-env-gotchas.md）：`expand` 用 `"$WINDIR\System32\expand.exe"`；`reg add` 开关写 `//v //t //d //f`；YAML 块标量内 heredoc 的 EOF 必须在块基准缩进上；重量级钩子用 `bash -c '...'` 包裹
- **调研子代理防崩溃**：提示词必须含「不写入任何图片/base64 数据」约束（上游 image_url 报错会直接杀子代理）
