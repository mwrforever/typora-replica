## 2. 官方核对结论

### 2.1 S3 字数统计（状态栏细节）

- 按钮位置官方未载明（截图承载）→ 自定状态栏右侧
- 弹面板含四项：行数/字数/字符数/估计阅读时间（排列官方未载明 → 自定按此顺序）；**面板内选择对应条目即切换默认计数单位**（官方载明，控件形态自定=点击条目行）
- 选中文字时按钮显示选中部分统计值（形态官方未载明 → 自定「选中 N / 总 N」并排）
- 显隐联动 Show Status Bar（12.1，归 10 设置）；「real time」实时更新语义
- 官方口径：字数不含格式符号、字符数含；中文一字一词；**默认显示字数；代码块文本计入（用户实测）**

### 2.2 状态栏其他图标（Spellcheck 页）

- 拼写检查图标（点击打开拼写面板，官方载明；「hover over the status bar」暗示悬浮出现）；语言切换双入口（面板 Global Setting… + 偏好面板）；词典警告图标；词典下载进度；中文/日文无拼写检查（选中文时用 en-US 查 ASCII 词）
- **裁决：拼写检查低优先 → 状态栏拼写/词典/下载图标首版占位延后**（Tauri WebView2 无系统拼写集成 API，自研词典成本与低优先定位不符）

### 2.3 F2 侧栏开关按钮

- Windows/Linux 侧栏开关入口在状态栏（官方载明）；按钮形态官方文字未载明 → 自定左侧图标按钮；**渲染归 11、开关逻辑归 03/12**

## 4. 开源生态边界

- **订阅链路**：updated 200ms 防抖**内置**（lodash debounce 尾沿，源码确认）；`addToHistory:false` 事务不触发；selectionUpdated 每笔事务即时触发（prevSelection 初始 null）
- **全量统计**：`doc.descendants` 遍历 text 节点；code_block `content:'text*'` + CodeMirror 编辑回写 text 节点 → **代码块天然计入**（用户实测 Typora 亦计入，无需过滤）
- **计词规则**：CJK 表意文字逐字计 1 词；拉丁字母/数字连续串按 1 词；标点空白不计；日语假名/韩文自定按「Unicode 字母连续串计词，仅中文逐字」
- **选中统计**：`doc.nodesBetween(from, to, ...)` 逐 text 节点累计（比 doc.cut 省复制、比 textBetween 无误计分隔符）
- **阅读时间** = 字数 ÷ Reading Speed，向上取整；Reading Speed 为 0/未设置时隐藏阅读时间行
- **UI**：状态栏容器由 12 渲染（底部单一实例）；11 输出 StatusBar.vue（左区侧栏按钮+拼写占位、右区字数按钮）+ 统计弹面板（Teleport 浮层、锚定按钮上方、点外关闭）
- **性能**：O(n) 字符遍历毫秒级；200ms 防抖已内置；不需要增量缓存
