## 1. 模块定位与边界

**做什么**：HTML/HTML 无样式/PDF 导出（首版范围，用户已拍板）、重复导出两命令、导出项管理、导出位置；Print 打印。**PDF 书签首版降级可延后**（CDP 实验性参数不透传时）。

**不做什么**：

- 图片长图（X4 首版不做，菜单占位禁用）
- Pandoc 全格式（X5 延后，自定义命令导出项保留占位）
- 云上传（无关）

## 2. 功能点细化（验收标准驱动）

### X1 HTML 导出

- 行为：独立单文件内嵌样式（主题 CSS + KaTeX CSS + 导出专用 CSS 合并 `<style>`）；Include Outline 默认关（形态跟随 Flat/Collapsible）；Append head/body；主题默认当前可另选；**YAML 变量替换仅限 `<title>/<meta>` 内（防 XSS）**；`<title>` 默认 = YAML title 优先，无则文件名

| 编号    | 类型 | 验收标准                                                                            |
| ------- | ---- | ----------------------------------------------------------------------------------- |
| AC-X1-1 | 正常 | Given 文档导出 HTML，Then 生成单文件且样式内嵌                                      |
| AC-X1-2 | 正常 | Given 开启 Include Outline，Then 导出 HTML 含大纲（形态跟随 Flat/Collapsible 设置） |
| AC-X1-3 | 正常 | Given YAML 含 title，Then 导出 `<title>` 被替换                                     |
| AC-X1-4 | 异常 | Given YAML 变量出现在正文（非 meta），Then 不被替换（防 XSS）                       |
| AC-X1-5 | 正常 | Given 文档含数学与 mermaid 图表，Then 导出 HTML 中渲染为 KaTeX HTML 与内联 SVG      |

### X2 PDF 导出

- 行为：默认 A4；页眉页脚默认空（`${title}/${pageNo}/${pageCount}` 变量经 Chrome 131+ @page margin boxes + counter(page/pages)）；h1 分页开关默认关 + 脚注前分页；手动分页 div 生效；暗色主题跟随当前主题（printBackground）；**PDF 书签首版降级可延后**
- 实现：隐藏 webview 渲染导出 HTML → Windows 自研 command（ICoreWebView2_16 PrintToPdfStream 或 CDP Page.printToPDF）

| 编号    | 类型 | 验收标准                                                          |
| ------- | ---- | ----------------------------------------------------------------- |
| AC-X2-1 | 正常 | Given 导出 PDF，Then 生成 A4 尺寸 PDF 文件                        |
| AC-X2-2 | 正常 | Given 配置页眉页脚变量，Then PDF 页眉含标题、页脚含页码           |
| AC-X2-3 | 边界 | Given 开启 h1 分页开关，Then 每个 h1 章节从新页开始               |
| AC-X2-4 | 正常 | Given 暗色主题下导出 PDF，Then 页面背景按暗色渲染（跟随当前主题） |
| AC-X2-5 | 异常 | Given 打印管线失败（Print Spooler 不可用），Then 错误提示不崩溃   |

### X3 HTML 无样式

| 编号 | 类型 | 验收标准 |
| --- | --- |
| AC-X3-1 | 正常 | Given 导出 HTML 无样式，Then 输出纯语义 HTML（无 style 无包裹类） |

### X6 重复导出

- 行为：两命令——Export with Previous（用上次成功设置）/ Export and Overwrite with Previous（覆盖上次文件 + 覆盖警告）；记忆范围=当前窗口+当前文档（会话级，前端内存 + 文档 id）

| 编号    | 类型 | 验收标准                                                                  |
| ------- | ---- | ------------------------------------------------------------------------- |
| AC-X6-1 | 正常 | Given 导出成功后按 Export with Previous，Then 用最近设置再次导出          |
| AC-X6-2 | 边界 | Given 按 Overwrite with Previous，Then 弹覆盖警告后覆盖上次导出文件       |
| AC-X6-3 | 边界 | Given 换文档导出，Then 之前文档的「上次设置」不串（会话级记忆按文档隔离） |

### X7 导出项管理

- 行为：列表增删改序；内置 4 项（PDF/HTML/HTML 无样式/Image）锁定不可重排/改名/删；改动实时作用于 File → Export 菜单

| 编号    | 类型 | 验收标准                                        |
| ------- | ---- | ----------------------------------------------- |
| AC-X7-1 | 正常 | Given 新增自定义导出项，Then 出现在 Export 菜单 |
| AC-X7-2 | 边界 | Given 尝试删除内置 PDF 项，Then 被拒绝（锁定）  |

### X8 导出位置

- 行为：三选项 auto/同目录/自定义；auto 自定 = 同当前文档目录（未命名文档 = 上次导出目录）；导出时仍可改路径

| 编号    | 类型 | 验收标准                                                     |
| ------- | ---- | ------------------------------------------------------------ |
| AC-X8-1 | 正常 | Given 设置为自定义目录，When 导出，Then 对话框默认定位该目录 |
| AC-X8-2 | 边界 | Given auto 模式已保存文档导出，Then 默认路径为文档所在目录   |

### X4/X5（留档，首版不做）

- X4 图片长图（640px/24px/Quality 四档）；X5 Pandoc 全格式与自定义命令导出（Command 变量替换/在文件所在目录执行/三态保存对话框）——菜单占位禁用，设置项保留占位。

## 3. 非功能要求

- **性能**：导出管线在隐藏 webview 中执行不阻塞编辑；大文档导出等待字体/图片加载完成后触发打印
- **安全**：YAML 变量替换仅 title/meta（防 XSS）；自定义命令引号剥离重包（防注入，X5 留档）

## 4. 测试策略

- **前端 Vitest**（核心 100%）：HTML 管线（DOMSerializer + 三类后处理 + CSS 内联）、变量替换白名单、导出设置组合、X6 会话级记忆
- **Rust 单测**（核心 100%）：打印 command 封装参数、PDF 落盘
- **E2E**：HTML 导出产物验证、PDF 导出冒烟（本地 CDP/WebDriver + 打印管线）
- **CI**：cargo test + Vitest 全绿

## 5. 依赖与接口

- **消费**：01（DOMSerializer 序列化 + 数学/图表渲染）、02（write_file）、05（Flat/Collapsible 设置 + heading 收集）、08（主题 CSS 文本）、10（导出设置 store）
- **提供**：
  - `exportService`（前端）：exportHtml/exportPdf/exportPlainHtml 管线
  - Rust command：`export_pdf(html_path, settings)`（隐藏 webview + 打印管线）
- **前端↔Rust 边界**：PDF 打印管线 Rust 侧（webview2-com）；HTML 生成前端侧
