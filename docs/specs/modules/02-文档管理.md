## 1. 模块定位与边界

**做什么**：文件的打开/保存/另存、最近文件、启动行为、自动保存、未保存草稿备份与恢复、文本编码处理，以及支撑上述能力的 Rust 侧文件 IO command（遍历/监视/读写/原子写）。

**不做什么**：

- 文件树 UI 渲染与右键菜单交互（03 文件树，本模块只提供 Rust command 与打开命令）
- 多标签状态管理（04）
- 全局搜索的搜索逻辑（06，本模块只提供读文件 command）
- 图片存盘（07）
- 窗口级菜单装配（12）

## 2. 功能点细化（验收标准驱动）

### F1 打开

- 行为：File → Open 对话框可选文件或文件夹；打开单文件时其父目录自动加载为侧栏目录；侧栏底部菜单可切换文件夹

| 编号    | 类型 | 验收标准                                                             |
| ------- | ---- | -------------------------------------------------------------------- |
| AC-F1-1 | 正常 | Given 点击 File → Open 选择文件夹，Then 该文件夹加载为侧栏当前目录   |
| AC-F1-2 | 正常 | Given 打开单个 .md 文件，Then 该文件在编辑器打开且其父目录加载到侧栏 |
| AC-F1-3 | 边界 | Given 打开不存在的路径（命令行参数传入），Then 提示错误且不崩溃      |
| AC-F1-4 | 正常 | Given 侧栏底部菜单选择切换文件夹，Then 当前目录切换且文件树刷新      |

### F11 Open Quickly

- 行为：Ctrl+P 弹出模糊搜索面板，搜索当前文件夹与最近文件（含固定文件夹）；选中即打开

| 编号     | 类型 | 验收标准                                                  |
| -------- | ---- | --------------------------------------------------------- |
| AC-F11-1 | 正常 | Given 按 Ctrl+P，Then 弹出搜索面板                        |
| AC-F11-2 | 正常 | Given 输入文件名片段，Then 模糊匹配当前文件夹内文件并排序 |
| AC-F11-3 | 正常 | Given 选中结果按 Enter，Then 打开该文件                   |
| AC-F11-4 | 异常 | Given 无匹配结果，Then 显示空态提示不崩溃                 |

### F13 最近文件

- 行为：打开文件/文件夹即记录；File → Open Recent 菜单列出；Clear Items 清除（固定项默认保留）；列表上限 10 条（自定）

| 编号     | 类型 | 验收标准                                                                 |
| -------- | ---- | ------------------------------------------------------------------------ |
| AC-F13-1 | 正常 | Given 打开一个文件，Then 其出现在 Open Recent 列表首位                   |
| AC-F13-2 | 边界 | Given 连续打开 12 个文件，Then 列表只保留最近 10 条                      |
| AC-F13-3 | 正常 | Given 点击 Clear Items，Then 列表清空但固定项保留                        |
| AC-F13-4 | 正常 | Given 点击 Open Recent 条目，Then 打开对应文件（不存在时提示并移除条目） |

### F14 启动行为

- 行为：四选项——新建文件/恢复上次文件夹/恢复上次文件与文件夹/自定义文件夹；命令行参数 `--new`/`--reopen-file` 覆盖设置

| 编号     | 类型 | 验收标准                                                                       |
| -------- | ---- | ------------------------------------------------------------------------------ |
| AC-F14-1 | 正常 | Given 设置为「恢复上次文件夹」，When 重启应用，Then 恢复上次打开的文件夹       |
| AC-F14-2 | 正常 | Given 设置为「恢复上次文件与文件夹」，When 重启，Then 恢复文件夹并重开上次文件 |
| AC-F14-3 | 边界 | Given 设置「恢复上次文件夹」但传 `--new` 启动，Then 忽略设置新建未命名文档     |
| AC-F14-4 | 异常 | Given 恢复目标路径已不存在，Then 回退新建文档并提示                            |

### F30 自动保存

- 行为：偏好面板开关型功能；**默认态：Typora 默认关，我们差异化默认开**（待把关确认）；触发双条件：停笔防抖（约 1s）∪ 定时器（默认 5 分钟，autoSaveTimer 可配）；写盘 UTF-8 无 BOM、行尾按 Default Line Ending 设置（LF 默认/CRLF 可配）、原子写（临时文件 + 重命名）

| 编号     | 类型 | 验收标准                                                   |
| -------- | ---- | ---------------------------------------------------------- |
| AC-F30-1 | 正常 | Given 编辑停笔约 1 秒，Then 内容自动写盘（防抖触发）       |
| AC-F30-2 | 正常 | Given 持续编辑不停笔，Then 最长 5 分钟定时写盘（定时兜底） |
| AC-F30-3 | 边界 | Given 关闭自动保存开关，Then 只有手动 Ctrl+S 写盘          |
| AC-F30-4 | 正常 | Given 保存成功，Then 脏状态清除（dirty=false，联动 C2）    |
| AC-F30-5 | 异常 | Given 写盘失败（磁盘只读），Then 提示错误且文档不标脏清除  |

### F31 草稿备份与恢复

- 行为：崩溃/异常退出未保存内容可找回（与自动保存开关无关）；**正常退出也留备份**（用户实测）；备份名 `{YYYY-MM-DD}-{文件名}.md`，未命名文档以首标题/首句命名；恢复入口为偏好面板 Save & Recover 分区的 Recover Unsaved Drafts 按钮；**不自动弹恢复提示**（用户实测）

| 编号     | 类型 | 验收标准                                                                            |
| -------- | ---- | ----------------------------------------------------------------------------------- |
| AC-F31-1 | 正常 | Given 编辑有未保存内容后异常退出，Then 备份目录存在 `{YYYY-MM-DD}-{文件名}.md` 草稿 |
| AC-F31-2 | 正常 | Given 未命名文档有内容，Then 草稿文件名取首标题                                     |
| AC-F31-3 | 正常 | Given 点击 Recover Unsaved Drafts 按钮，Then 列出可恢复草稿并可打开                 |
| AC-F31-4 | 边界 | Given 正常退出应用，Then 草稿备份仍在（不因正常退出丢失）                           |
| AC-F31-5 | 异常 | Given 草稿内容为空，Then 不产生空草稿文件                                           |

### C3 编码

- 行为：读取 UTF-8 无 BOM 默认；**GBK 探测为差异化增强**（Typora 无探测、乱码即所见、保存转 UTF-8）；保存一律 UTF-8 无 BOM

| 编号    | 类型 | 验收标准                                                    |
| ------- | ---- | ----------------------------------------------------------- |
| AC-C3-1 | 正常 | Given 打开 UTF-8 无 BOM 文件，Then 中文正常显示             |
| AC-C3-2 | 正常 | Given 打开 UTF-8 带 BOM 文件，Then BOM 被剥离且内容正常显示 |
| AC-C3-3 | 边界 | Given 打开 GBK 编码文件，Then 探测后正常显示（差异化增强）  |
| AC-C3-4 | 正常 | Given 保存文档，Then 落盘为 UTF-8 无 BOM                    |
| AC-C3-5 | 边界 | Given 设置为 CRLF 行尾，When 保存，Then 落盘 CRLF；默认 LF  |

## 3. 非功能要求

- **性能**：markdownUpdated 高频事件必须防抖合并；getMarkdown() O(n) 全量序列化只在防抖窗口末端执行一次
- **原子性**：写盘用临时文件 + 重命名，防止中途断电损坏
- **路径安全**：所有 Rust command 校验路径合法性（拒绝 `../` 逃逸到未授权目录）

## 4. 测试策略

- **Rust 单元测试**：编码探测（UTF-8/BOM/GBK）、原子写、草稿命名规则、行尾转换——**核心功能 100% 覆盖**（编码与写盘属数据安全路径）
- **前端 Vitest**：防抖定时器逻辑（fake timers）、最近文件列表去重与上限
- **E2E**：打开→编辑→自动保存→重启恢复链路（本地 CDP/WebDriver）
- **CI**：cargo test + Vitest 全绿

## 5. 依赖与接口

- **消费**（来自 01）：编辑器实例接口（getMarkdown/setReadonly）、markdownUpdated 事件
- **提供**（Rust command，供 03/04/06/09/12 消费）：
  - `list_dir(path) -> DirEntry[]`（递归遍历 + 扩展名过滤 + 自然序排序）
  - `read_file(path) -> { content, encoding, lineEnding }`（BOM 嗅探 + UTF-8/GBK 探测）
  - `write_file(path, content, opts)`（原子写 + 行尾转换）
  - `save_draft(path, content)` / `list_drafts()` / `recover_draft()`
  - `watch_dir(path)`（notify 事件流，供 03 刷新）
  - `recent_files` 读写（store 插件）
- **持久化**：最近文件/启动行为用 tauri-plugin-store；草稿在自定 app 数据目录 drafts/
- **前端↔Rust 边界**：全部文件 IO 走 Rust command（方案 C，绕开 fs 插件静态 scope 约束）
