## 1. 模块定位与边界

**做什么**：主题体系——主题目录管理、Themes 菜单（列出全部 .css）、明暗分离与系统联动、自定义 CSS 追加（base.user.css/{theme}.user.css）、热刷新、自定义字体、DevTools 开关；内置主题（原创 CSS，按 Crepe 22 变量体系原生编写）。

**不做什么**：

- 主题市场（T9，外链第三方）
- 菜单栏装配（12，本模块只提供主题列表数据）
- Typora 主题文件的 100% 兼容（DOM 结构差异，映射层兜底为尽力而为）

## 2. 功能点细化（验收标准驱动）

### T1 主题即 CSS

- 行为：Themes 菜单列出主题目录全部 .css；内置主题原创编写（Typora 官方 6 主题为风格参考：GitHub/Gothic/Newsprint/Night/Pixyll/Whitey）

| 编号    | 类型 | 验收标准                                                            |
| ------- | ---- | ------------------------------------------------------------------- |
| AC-T1-1 | 正常 | Given 主题目录含 3 个 .css，Then Themes 菜单列出 3 个主题（含内置） |
| AC-T1-2 | 正常 | Given 选择某主题，Then 界面即时切换该主题样式                       |

### T2 主题目录

- 行为：Appearance 分区 Open Theme Folder 按钮；应用数据目录 themes/（自定路径）

| 编号    | 类型 | 验收标准                                                  |
| ------- | ---- | --------------------------------------------------------- |
| AC-T2-1 | 正常 | Given 点击 Open Theme Folder，Then 资源管理器打开主题目录 |

### T3 安装主题

- 行为：复制 css+资源到主题目录；官方基线=重启可见；**热刷新（notify 监视目录）为差异化增强（已拍板）**

| 编号    | 类型 | 验收标准                                                                             |
| ------- | ---- | ------------------------------------------------------------------------------------ |
| AC-T3-1 | 正常 | Given 复制新主题 css 到目录，Then 热刷新后出现在 Themes 菜单（无需重启，差异化增强） |
| AC-T3-2 | 正常 | Given 修改已激活主题的 css，Then 界面即时刷新                                        |

### T4 命名规则

- 行为：小写字母 + 连字符（**数字禁用**，官方「非字母字符仅 -」）；菜单标签 = 连字符分词 + 每词首字母大写（my-first-theme → "My First Theme"）

| 编号    | 类型 | 验收标准                                                        |
| ------- | ---- | --------------------------------------------------------------- |
| AC-T4-1 | 正常 | Given `my-first-theme.css`，Then 菜单标签 "My First Theme"      |
| AC-T4-2 | 边界 | Given `theme2.css`（含数字），Then 不出现在菜单（对齐官方规则） |
| AC-T4-3 | 边界 | Given `MyTheme.css`（大写），Then 不出现在菜单                  |

### T5 明暗分离

- 行为：亮/暗模式分别指定主题；系统色系变化联动（Tauri Theme 链路 → WebView2 PreferredColorScheme → matchMedia 选择注入）；主题内 prefers-color-scheme 自适应支持

| 编号    | 类型 | 验收标准                                                          |
| ------- | ---- | ----------------------------------------------------------------- |
| AC-T5-1 | 正常 | Given 分别设置亮/暗主题，When 切换系统明暗，Then 对应主题自动应用 |
| AC-T5-2 | 边界 | Given 主题内用 media query 自适应，Then 明暗切换时主题自适应生效  |

### T6 自定义 CSS 追加

- 行为：4 层加载顺序（基础→主题 CSS→base.user.css→{theme}.user.css）；大小写敏感；落 Crepe 变量覆盖层

| 编号    | 类型 | 验收标准                                               |
| ------- | ---- | ------------------------------------------------------ |
| AC-T6-1 | 正常 | Given base.user.css 存在，Then 其样式对所有主题生效    |
| AC-T6-2 | 正常 | Given `{theme}.user.css` 存在，Then 其样式仅该主题生效 |
| AC-T6-3 | 边界 | Given 文件名大小写不匹配，Then 不生效（大小写敏感）    |

### T7 DevTools

- 行为：View → Toggle DevTools（Shift+F12）；debug 构建默认开、release 需 feature flag

| 编号    | 类型 | 验收标准                                             |
| ------- | ---- | ---------------------------------------------------- |
| AC-T7-1 | 正常 | Given debug 构建按 Shift+F12，Then DevTools 开合切换 |

### T8 自定义字体

- 行为：@font-face 引用主题目录 fonts/；相对路径基准=主题目录；**内置主题用 rem 字号单位**（配合字号偏好）

| 编号    | 类型 | 验收标准                                                          |
| ------- | ---- | ----------------------------------------------------------------- |
| AC-T8-1 | 正常 | Given 主题引用 `./fonts/x.woff2`，Then 字体正确加载               |
| AC-T8-2 | 边界 | Given 内置主题设置 rem 字号，When 调整字号偏好，Then 全文字号跟随 |

### T9 主题市场（不做）

- Gallery 外链第三方，首版不做（留档）。

## 3. 非功能要求

- **兼容策略（已拍板）**：内置主题按 Crepe 22 个 `--crepe-*` 变量原生编写；用户 Typora 主题经变量映射层兜底（官方 15 个常用变量 --bg-color/--text-color/--primary-color 等），DOM 结构差异导致的还原度损失如实接受
- **安全**：asset 协议 scope 限定主题目录；CSP style-src/font-src/img-src 放行 asset:

## 4. 测试策略

- **Rust 单测**（核心 100%）：主题目录扫描、命名规则校验（数字/大写拒绝）、菜单标签转换算法
- **前端 Vitest**：明暗切换链路、CSS 注入顺序（4 层）、热刷新事件
- **E2E**：安装主题→菜单出现→切换生效（本地 CDP/WebDriver）
- **CI**：cargo test + Vitest 全绿

## 5. 依赖与接口

- **消费**：02 read_file（主题 CSS 读取）、10 设置 store（明暗主题选择、字号）
- **提供**：
  - `themeStore`（Pinia）：主题列表/当前亮暗主题/自定义 CSS 状态
  - Rust command：`list_themes()`、`watch_themes()`（热刷新事件）
  - 主题 CSS 注入服务（供 01 编辑器消费 Crepe 变量覆盖层、09 导出消费主题 CSS 文本）
- **前端↔Rust 边界**：主题 CSS 经 asset 协议 link 注入；目录监视 Rust notify
