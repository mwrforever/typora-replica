## 1. 模块定位与边界

**做什么**：侧边栏的文件树/文件列表面板 UI 与交互——三面板切换、过滤、右键菜单、自动刷新、排序、拖入插链接、最近位置、全局搜索入口。

**不做什么**：

- 目录遍历/监视/文件 IO 实现（02 的 Rust command）
- 大纲面板（05）
- 全局搜索的搜索逻辑（06）
- 侧边栏整体布局容器与装配（12 窗口外壳）
- 树内拖拽移动、撤销文件操作（首版延后）

## 2. 功能点细化（验收标准驱动）

### F2 侧边栏切换

- 行为：文件树/大纲/文件列表三面板；Ctrl+Shift+L 开关；Ctrl+Shift+1/2/3 面板切换；**Windows/Linux 侧栏开关入口在状态栏**（联动 11 状态栏）

| 编号    | 类型 | 验收标准                                                       |
| ------- | ---- | -------------------------------------------------------------- |
| AC-F2-1 | 正常 | Given 按 Ctrl+Shift+L，Then 侧边栏显隐切换                     |
| AC-F2-2 | 正常 | Given 按 Ctrl+Shift+1/2/3，Then 切换到大纲/文件列表/文件树面板 |
| AC-F2-3 | 正常 | Given 点击状态栏侧栏按钮，Then 侧边栏开关（Windows 入口行为）  |

### F3 文件树过滤

- 行为：只显示受支持类型——**14 种扩展名白名单**（.md/.markdown/.mdown/.mmd/.text/.txt/.rmarkdown/.mkd/.mdwn/.mdtxt/.rmd/.qmd/.mdtext/.mdx）；隐藏文件不显示；无扩展名文本不显示

| 编号    | 类型 | 验收标准                                                       |
| ------- | ---- | -------------------------------------------------------------- |
| AC-F3-1 | 正常 | Given 目录含 .md/.txt/.png/.docx 文件，Then 只显示 .md 与 .txt |
| AC-F3-2 | 边界 | Given 目录含 .qmd/.rmarkdown 文件，Then 显示（14 种白名单内）  |
| AC-F3-3 | 边界 | Given 目录含隐藏文件（.开头的文件与目录），Then 不显示         |
| AC-F3-4 | 边界 | Given 目录含无扩展名文本文件，Then 不显示                      |

### F4 右键菜单

- 行为：右键菜单 12 项——打开/新窗口打开/新建文件/新建文件夹/重命名/Duplicate/删除（回收站）/撤销文件操作/复制路径/在资源管理器中显示/搜索/最近位置；新建文件内联输入文件名、确认免弹窗；Duplicate 命名自定 `{原名} copy.{ext}`（冲突追加 -1）

| 编号    | 类型 | 验收标准                                                                                     |
| ------- | ---- | -------------------------------------------------------------------------------------------- |
| AC-F4-1 | 正常 | Given 文件树空白处右键 → 新建文件 → 输入 `test.md` 回车，Then 文件创建并进入命名态免二次确认 |
| AC-F4-2 | 正常 | Given 文件右键 → Duplicate，Then 生成 `{原名} copy.md`                                       |
| AC-F4-3 | 正常 | Given 文件右键 → 删除，Then 文件移入回收站（trash，非永久删除）                              |
| AC-F4-4 | 正常 | Given 文件右键 → 在资源管理器中显示，Then 资源管理器打开并选中该文件                         |
| AC-F4-5 | 边界 | Given 重命名输入非法字符（`?` `*`），Then 提示错误不创建                                     |
| AC-F4-6 | 边界 | Given Duplicate 目标已存在，Then 命名追加 -1                                                 |

### F5 自动刷新

- 行为：监视目录变更自动刷新文件树（notify 事件流 + 防抖）；侧栏菜单手动 Refresh 兜底

| 编号    | 类型 | 验收标准                                                              |
| ------- | ---- | --------------------------------------------------------------------- |
| AC-F5-1 | 正常 | Given 外部程序在目录新建文件，Then 文件树自动出现该文件（防抖窗口内） |
| AC-F5-2 | 正常 | Given 外部程序删除文件，Then 文件树自动移除                           |
| AC-F5-3 | 正常 | Given 点击手动 Refresh，Then 强制重扫目录                             |

### F6 排序

- 行为：四种排序（字母/自然序/修改时间/创建时间）各可升降序；**Group by Folder 开关（文件夹置前，默认开）**；自然序语义：数字段按数值比较（1-xxx、2-xxx、10-xxx）

| 编号    | 类型 | 验收标准                                                                           |
| ------- | ---- | ---------------------------------------------------------------------------------- |
| AC-F6-1 | 正常 | Given 默认 Group by Folder 开，Then 文件夹全部排在文件前                           |
| AC-F6-2 | 边界 | Given 关闭 Group by Folder，Then 文件夹与文件按排序规则混排                        |
| AC-F6-3 | 正常 | Given 自然序排序文件 `1-xxx`/`2-xxx`/`10-xxx`，Then 顺序为 1、2、10（非 1、10、2） |
| AC-F6-4 | 正常 | Given 按修改时间排序，Then 最近修改在前（降序）                                    |

### F7 拖入编辑器插链接

- 行为：文件/文件夹从侧栏拖入写作区插入链接（相对路径含扩展名）；树内拖拽移动与系统文件管理器互拖首版延后

| 编号    | 类型 | 验收标准                                                                         |
| ------- | ---- | -------------------------------------------------------------------------------- |
| AC-F7-1 | 正常 | Given 拖拽文件树中 `readme.md` 到编辑器，Then 插入 `[readme.md](readme.md)` 链接 |
| AC-F7-2 | 边界 | Given 拖拽子目录中文件到编辑器，Then 插入相对路径链接（`[x](sub/x.md)` 形式）    |
| AC-F7-3 | 异常 | Given 拖拽文件夹到编辑器，Then 插入文件夹链接而非报错                            |

### F9 最近位置

- 行为：侧栏最近位置列表（打开过的文件夹）；hover 出现移除（trash）/固定（Pin）按钮；固定项联动出现在 Open Recent 菜单与 Open Quickly；上限 10 条（自定）

| 编号    | 类型 | 验收标准                                                          |
| ------- | ---- | ----------------------------------------------------------------- |
| AC-F9-1 | 正常 | Given 打开一个文件夹，Then 其出现在最近位置列表                   |
| AC-F9-2 | 正常 | Given 点击 Pin 固定一个位置，Then 其置顶且不被新记录挤出          |
| AC-F9-3 | 正常 | Given 点击移除按钮，Then 该位置从列表删除                         |
| AC-F9-4 | 边界 | Given 打开超过 10 个文件夹，Then 列表保留最近 10 条（固定项除外） |

### F12 全局搜索入口

- 行为：**Ctrl+Shift+F 打开全局搜索**；Windows/Linux 入口为滚动到侧栏顶部显示搜索框；侧栏在 Outline 面板时自动切到文件树（自定）；搜索逻辑归 06

| 编号     | 类型 | 验收标准                                                                                 |
| -------- | ---- | ---------------------------------------------------------------------------------------- |
| AC-F12-1 | 正常 | Given 按 Ctrl+Shift+F，Then 侧栏显示全局搜索框                                           |
| AC-F12-2 | 边界 | Given 侧栏当前在 Outline 面板，When 按 Ctrl+Shift+F，Then 自动切到文件树面板并显示搜索框 |
| AC-F12-3 | 正常 | Given 侧栏隐藏，When 按 Ctrl+Shift+F，Then 侧栏展开显示搜索框                            |

## 3. 非功能要求

- **性能**：万文件目录树渲染流畅（虚拟滚动或分帧渲染）；目录变更事件防抖（如 300ms 窗口）避免风暴
- **一致性**：扩展名白名单与 C3 编码探测共用同一份常量

## 4. 测试策略

- **Rust 单测**：扩展名过滤、自然序比较器、排序组合——核心 100%（过滤与排序属数据正确性路径）
- **前端 Vitest**：树组件渲染（含隐藏文件过滤）、右键菜单动作分发、拖拽事件处理
- **E2E**：新建→重命名→删除→回收站恢复、外部变更自动刷新（本地 CDP/WebDriver）
- **CI**：cargo test + Vitest 全绿

## 5. 依赖与接口

- **消费**（来自 02）：`list_dir(path)`（含扩展名过滤与排序参数的遍历）、`watch_dir` 事件流、打开文件/文件夹命令、recent_folders 持久化
- **消费**（来自 01）：编辑器实例接口（拖入插链接时插入 markdown 链接文本）
- **提供**：
  - `fileTreeStore`（Pinia）：当前目录/树数据/选中项/排序状态/Group by Folder 开关
  - 事件 `open-file(path)`（供 04 打开标签）、`request-search()`（供 06）
  - 状态栏开关入口事件（供 11 状态栏）
- **前端↔Rust 边界**：全部文件操作走 02 的 Rust command；删除用 trash crate（回收站，非永久删除）
