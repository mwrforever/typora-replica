## 1. 模块定位与边界

**做什么**：状态栏 UI（字数按钮 + 统计弹面板 + 侧栏开关按钮 + 拼写图标占位）与字数统计逻辑（全量/选中/阅读时间）。

**不做什么**：

- 状态栏容器渲染（12 窗口外壳，11 通过插槽提供内容）
- Reading Speed 设置项本身（10 设置，11 消费其值）
- 侧栏开关逻辑（03/12，11 只渲染按钮转发事件）
- 拼写检查功能（低优先，图标占位延后）

## 2. 功能点细化（验收标准驱动）

### S3 字数统计

- 行为：状态栏按钮显示当前计数单位统计值（**默认字数**，用户实测）；选中文字时显示「选中 N / 总 N」；点击弹面板（行数/字数/字符数/估计阅读时间四项，按此顺序）；**点击面板条目切换默认计数单位**；中文一字一词（CJK 逐字计 1 词，拉丁连续串按词计）；**代码块文本计入**（用户实测）；字符数口径 = 渲染级全部 text 字符数（与官方源码级口径差异已标注）；阅读时间 = 字数 ÷ Reading Speed 向上取整（Reading Speed 为 0 时隐藏）；**绑定活动标签页文档**（多标签差异项）

| 编号    | 类型 | 验收标准                                                                |
| ------- | ---- | ----------------------------------------------------------------------- |
| AC-S3-1 | 正常 | Given 文档含「Hello 世界」，Then 状态栏显示 3 词（Hello=1、世=1、界=1） |
| AC-S3-2 | 正常 | Given 点击字数按钮，Then 弹出面板显示行数/字数/字符数/阅读时间四项      |
| AC-S3-3 | 正常 | Given 面板点击「字符数」条目，Then 默认计数单位切换为字符数             |
| AC-S3-4 | 边界 | Given 选中一段文字，Then 按钮显示「选中 N / 总 N」                      |
| AC-S3-5 | 边界 | Given 代码块含 10 个词，Then 计入字数（标记符不计）                     |
| AC-S3-6 | 边界 | Given Reading Speed 为 0，Then 面板隐藏阅读时间行                       |
| AC-S3-7 | 正常 | Given 切换标签页，Then 状态栏统计切换为新活动标签的文档                 |
| AC-S3-8 | 异常 | Given 空文档，Then 显示 0 词不崩溃                                      |

### 状态栏 UI

- 行为：左区侧栏开关按钮（渲染归 11、逻辑转发 03/12）、拼写图标占位（首版延后）；右区字数按钮；随 Show Status Bar 设置显隐（12 消费）

| 编号     | 类型 | 验收标准                                          |
| -------- | ---- | ------------------------------------------------- |
| AC-S3-9  | 正常 | Given 点击状态栏侧栏开关按钮，Then 侧边栏开合切换 |
| AC-S3-10 | 边界 | Given 关闭 Show Status Bar 设置，Then 状态栏隐藏  |

## 3. 非功能要求

- **性能**：updated 200ms 防抖内置；统计 O(n) 字符遍历毫秒级；选中统计 nodesBetween 区间遍历不复制子树；不需要增量缓存
- **一致性**：统计纯函数 `utils/word-count.ts` 与 Vue 组件解耦，口径是核心数据路径

## 4. 测试策略

- **前端 Vitest**（核心 100%）：计词规则（中文逐字/拉丁串/标点空白/代码块）、选中区间统计（nodesBetween 跨块）、阅读时间向上取整与 0 值隐藏、活动标签绑定
- **组件测试**：弹面板开合与单位切换、按钮显示形态
- **E2E**：状态栏随编辑实时更新（本地 CDP/WebDriver）
- **CI**：Vitest 全绿

## 5. 依赖与接口

- **消费**：
  - 01：编辑器实例、updated（200ms 防抖）/selectionUpdated（即时）事件
  - 10：settingsStore（Reading Speed、Show Status Bar）
  - 04：活动标签 id
- **提供**：
  - `StatusBar.vue`（左区插槽：侧栏开关按钮 + 拼写占位；右区：字数按钮 + 弹面板）
  - `wordCount` 纯函数工具（可被 12 或其他模块复用）
- **前端↔Rust 边界**：纯前端模块
