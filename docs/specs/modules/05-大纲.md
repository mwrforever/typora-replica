## 1. 模块定位与边界

**做什么**：侧边栏大纲面板——标题树渲染（层级缩进/扁平可折叠两视图）、点击跳转、当前标题高亮（滚动+编辑双通道）、关键词过滤、Highlight Current Header 找回、与 E12 TOC 共用 heading 收集函数。

**不做什么**：

- 侧边栏整体布局容器（12 窗口外壳）
- 文件树/文件列表面板（03）
- E12 TOC 节点本身（01 编辑核心）
- 导出 HTML/PDF 的大纲生成（09，本模块只提供 heading 收集函数与 Flat/Collapsible 设置值）

## 2. 功能点细化（验收标准驱动）

### F16 大纲面板开关

- 行为：Ctrl+Shift+1 切换到大纲面板；View → Outline 菜单；Windows/Linux 左下角按钮

| 编号     | 类型 | 验收标准                                               |
| -------- | ---- | ------------------------------------------------------ |
| AC-F16-1 | 正常 | Given 按 Ctrl+Shift+1，Then 侧栏显示大纲面板           |
| AC-F16-2 | 正常 | Given 点击 Windows 左下角大纲按钮，Then 切换到大纲面板 |

### F17 层级缩进

| 编号     | 类型 | 验收标准                                               |
| -------- | ---- | ------------------------------------------------------ |
| AC-F17-1 | 正常 | Given 文档含 H1/H2/H3，Then 大纲按层级缩进展示继承关系 |

### F18 点击跳转

| 编号     | 类型 | 验收标准                                                              |
| -------- | ---- | --------------------------------------------------------------------- |
| AC-F18-1 | 正常 | Given 点击大纲条目，Then 编辑器滚动到对应标题且光标定位标题处         |
| AC-F18-2 | 边界 | Given 点击文档底部标题条目，Then 滚动到可视区（不因超出文档长度报错） |

### F19 当前标题高亮

- 行为：滚动**与**编辑两种场景都高亮当前章节（双通道：滚动监听 + selectionUpdated）；判定规则 = 「最后一个 top ≤ 视口阈值」的标题

| 编号     | 类型 | 验收标准                                                |
| -------- | ---- | ------------------------------------------------------- |
| AC-F19-1 | 正常 | Given 滚动文档到某章节，Then 大纲中该章节标题高亮       |
| AC-F19-2 | 正常 | Given 光标在文档某标题下正文中编辑，Then 大纲高亮该标题 |
| AC-F19-3 | 边界 | Given 滚动到标题 A 与 B 之间，Then 高亮 A（前一个标题） |

### F20 Highlight Current Header

- 行为：右键菜单项；语义 = 操作过大纲面板（过滤/滚动）后找回当前标题；右键位置 = 大纲面板空白处（自定）

| 编号     | 类型 | 验收标准                                                                                                      |
| -------- | ---- | ------------------------------------------------------------------------------------------------------------- |
| AC-F20-1 | 正常 | Given 过滤大纲后当前标题不可见，When 右键面板空白处选 Highlight Current Header，Then 当前标题高亮且滚动到可见 |

### F21 大纲过滤

- 行为：面板顶部输入框（自定）、输入即滤、过滤时保留层级缩进（自定）

| 编号     | 类型 | 验收标准                                    |
| -------- | ---- | ------------------------------------------- |
| AC-F21-1 | 正常 | Given 输入关键词，Then 只显示匹配的标题条目 |
| AC-F21-2 | 边界 | Given 清空过滤词，Then 恢复完整大纲         |
| AC-F21-3 | 异常 | Given 无匹配标题，Then 显示空态提示         |

### F22 扁平/可折叠

- 行为：两视图切换；配置入口三处（View 菜单/偏好设置 Appearance「大纲视图允许折叠和展开」/大纲右键菜单）；**默认 Flat**（用户实测）；折叠状态按标题 id 匹配在重算时尽量保留

| 编号     | 类型 | 验收标准                                                                      |
| -------- | ---- | ----------------------------------------------------------------------------- |
| AC-F22-1 | 正常 | Given 默认状态，Then 大纲为 Flat 扁平视图                                     |
| AC-F22-2 | 正常 | Given 开启可折叠选项，Then 大纲可折叠/展开各层级                              |
| AC-F22-3 | 边界 | Given 折叠若干节点后编辑文档触发大纲重算，Then 折叠状态尽量保留（按 id 匹配） |

### F23 文档内 TOC（与 E12 共用）

- 行为：heading 收集函数与 E12 TOC 共用（放 01 模块工具层，05 与 TOC NodeView 复用）；PDF 书签与 HTML 导出大纲由 09 消费

| 编号     | 类型 | 验收标准                                                                                             |
| -------- | ---- | ---------------------------------------------------------------------------------------------------- |
| AC-F23-1 | 正常 | Given 文档含标题层级，Then heading 收集函数输出 {id, level, text, pos} 数组（被 E12 与导出模块复用） |

### 锚点 id 规则（跨模块决策，落地在 01，05 消费）

- **重复标题锚点从 `-1` 起编号**（对齐 Typora，用户拍板）：`#hello`、`#hello-1`、`#hello-2`；中文标题 id 保留中文、空格转 `-`（与 Milkdown 默认一致）
- 实现：自写插件替代 sync-heading-id 的编号逻辑（Milkdown 默认 `-#2` 硬编码不可配）
- 向 01 模块提的接口变更：**补充暴露 `updated(doc)` 与 `selectionUpdated`**（Crepe on() 原生支持）

| 编号     | 类型 | 验收标准                                                                                |
| -------- | ---- | --------------------------------------------------------------------------------------- |
| AC-F23-2 | 正常 | Given 两个同名 `# Hello` 标题，Then 锚点 id 为 `hello` 与 `hello-1`（对齐 Typora 规则） |
| AC-F23-3 | 正常 | Given 中文标题 `第三章 数据结构设计`，Then id 为 `第三章-数据结构设计`                  |

## 3. 非功能要求

- **性能**：大纲重算基于 `updated` 内置 200ms 防抖 + heading 序列浅层 diff；万行文档（标题数百）普通递归渲染，虚拟列表仅作预案
- **一致性**：heading 收集函数是 E12/F23/09 导出的唯一数据源

## 4. 测试策略

- **前端 Vitest**（核心 100%）：heading 收集函数（层级/文本/位置）、锚点 id 生成规则（重复 -1 起编号/中文保留）、当前标题判定（滚动阈值/selection 上溯）、过滤 computed
- **组件测试**：Flat/Collapsible 视图渲染、折叠状态保留
- **E2E**：点击跳转、滚动高亮（本地 CDP/WebDriver）
- **CI**：Vitest 全绿

## 5. 依赖与接口

- **消费**（来自 01）：编辑器实例、`updated(doc)`、`selectionUpdated`（需 01 补充暴露）、heading 收集函数（放 01 工具层）
- **消费**（来自 02）：打开文档命令（大纲随活动标签切换重建）
- **提供**：
  - `outlineStore`（Pinia）：heading 列表/过滤词/Flat-Collapsible 设置/当前标题 id
  - heading 收集函数（与 E12 共用，09 导出消费）
  - Flat/Collapsible 设置值（09 导出消费）
- **前端↔Rust 边界**：纯前端模块
