## 1. 模块定位与边界

**做什么**：图片插入的存盘链路——onUpload 真实实现（Tauri 写盘 + 相对路径）、粘贴/拖拽/菜单三路插入、路径策略（相对/./ 前缀/URL 转义）、typora-root-url、Delete Image（确认+回收站）、单图居中与缩放。

**不做什么**：

- 云上传器（首版占位禁用）
- Move/Copy All Images 批量处理（延后）
- 主题 CSS 实现（08，P10 的 CSS 片段由 08 落地）
- 编辑器内图片渲染组件（01）

## 2. 功能点细化（验收标准驱动）

### P1 多方式插入

- 行为：4 种方式（手写语法/菜单 Ctrl+Shift+I/拖拽多文件/剪贴板粘贴）；菜单插入时剪贴板有图片 URL 则直写 src；Insert Local Images 无默认快捷键

| 编号    | 类型 | 验收标准                                                          |
| ------- | ---- | ----------------------------------------------------------------- |
| AC-P1-1 | 正常 | Given 菜单选择本地图片，Then 插入图片节点                         |
| AC-P1-2 | 正常 | Given 一次拖入 3 张图片，Then 全部插入                            |
| AC-P1-3 | 正常 | Given 剪贴板含图片时按 Ctrl+Shift+I，Then 剪贴板图片 URL 直写 src |
| AC-P1-4 | 异常 | Given 拖入非图片文件，Then 不插入图片（提示或忽略）               |

### P2 粘贴自动存盘

- 行为：三步开启（保存文档 → 开选项 → 选目标文件夹写入 typora-copy-images-to）；拖入/粘贴后复制到目标目录并更新 src；**重名直接覆盖（对齐 Typora，用户实测）**；粘贴截图文件名 `image-YYYYMMDD-HHMMSS.png`；粘贴图片 alt 为空（落盘 `![](path)`）；未保存文档 src 写绝对路径（用户实测）
- 实现：`save_image(bytes, name, target_dir) -> 相对 src`（原子写 + 文件名 sanitize + mime→扩展名）

| 编号    | 类型 | 验收标准                                                                                         |
| ------- | ---- | ------------------------------------------------------------------------------------------------ |
| AC-P2-1 | 正常 | Given 已保存文档开启 copy-to-folder，When 粘贴截图，Then 图片写入目标文件夹且 src 更新为相对路径 |
| AC-P2-2 | 正常 | Given 粘贴剪贴板截图，Then 文件名形如 `image-20260813-143000.png` 且 alt 为空                    |
| AC-P2-3 | 边界 | Given 同名文件再次粘贴，Then 直接覆盖原文件（对齐 Typora）                                       |
| AC-P2-4 | 边界 | Given 未保存文档粘贴图片，Then src 写绝对路径                                                    |
| AC-P2-5 | 异常 | Given 目标文件夹不可写，Then 提示错误且编辑器不崩溃                                              |

### P3 路径策略

- 行为：三开关默认全关（用户实测）；relative path（前提文档已保存）；./ prefix（官方推荐禁用）；**URL 转义 = escape() 语义**（`%uXXXX` UTF-16 码元，非 encodeURIComponent）

| 编号    | 类型 | 验收标准                                                                                      |
| ------- | ---- | --------------------------------------------------------------------------------------------- |
| AC-P3-1 | 正常 | Given 开启 relative path 且文档已保存，When 插入同目录图片，Then src 为相对路径               |
| AC-P3-2 | 正常 | Given 开启 URL 转义插入 `Name 名字.png`，Then src 为 `Name%20%u540D%u5B57.png`（escape 语义） |
| AC-P3-3 | 边界 | Given 开启 ./ prefix，Then src 带 `./` 前缀；默认关不带                                       |
| AC-P3-4 | 边界 | Given 图片跨盘符（相对路径不可计算），Then 降级绝对路径                                       |

### P4 根路径前缀

- 行为：typora-root-url（绝对路径值）；显示时解析（root + src 拼接），**不写入 src**

| 编号    | 类型 | 验收标准                                                                                                            |
| ------- | ---- | ------------------------------------------------------------------------------------------------------------------- |
| AC-P4-1 | 正常 | Given YAML 含 `typora-root-url: /root/` 且 src 为 `/blog/x.png`，Then 渲染解析为 `/root/blog/x.png` 且 src 保持原样 |

### P5 删除图片

- 行为：右键图片 → Delete Image → **确认对话框（提示文件将被删除）→ 确认后删引用 + 文件进回收站**（用户拍板）；多引用时提示仍被引用（增强）；src 解析失败仅删引用并提示

| 编号    | 类型 | 验收标准                                                      |
| ------- | ---- | ------------------------------------------------------------- |
| AC-P5-1 | 正常 | Given 右键图片选 Delete Image，Then 弹确认对话框              |
| AC-P5-2 | 正常 | Given 确认删除，Then 图片节点移除且磁盘文件进回收站（可恢复） |
| AC-P5-3 | 边界 | Given 取消删除，Then 引用与文件均保留                         |
| AC-P5-4 | 异常 | Given src 无法解析为磁盘文件，Then 仅删引用并提示             |

### P10 单图居中

- 行为：单图段落默认居中（官方三行 CSS：编辑态 `p .md-image:only-child`、导出态 `p > img:only-child`）；取消居中可用自定义 CSS

| 编号     | 类型 | 验收标准                                    |
| -------- | ---- | ------------------------------------------- |
| AC-P10-1 | 正常 | Given 段落中仅一张图，Then 该图水平居中显示 |

### P11 缩放

- 行为：`style="zoom:50%"`（HTML img 标签形式，Crepe html 节点天然兼容）；style 中其他属性编辑时忽略、导出时生效
- 定制 schema 后：markdown 图片拖拽缩放落盘格式（title 挂 ratio，与 alt 保真的联合决策）

| 编号     | 类型 | 验收标准                                                                 |
| -------- | ---- | ------------------------------------------------------------------------ |
| AC-P11-1 | 正常 | Given `<img src="x.png" style="zoom:50%">`，Then 编辑视图按 50% 缩放显示 |
| AC-P11-2 | 边界 | Given img style 含 zoom 以外的属性，Then 编辑视图忽略该属性、导出时保留  |

### alt 保真（联合 01 的 schema 定制，用户拍板）

- 行为：打开 `![描述](path)` 保存后 alt 不丢失；粘贴/拖拽插入落盘 `![](path)`（alt 空，对齐 Typora）；ratio 挪位（title 或新 attr）

| 编号     | 类型 | 验收标准                                                                                   |
| -------- | ---- | ------------------------------------------------------------------------------------------ |
| AC-P11-3 | 正常 | Given 打开含 `![描述](path.png)` 的文档，When 保存，Then alt「描述」原样保留（非 ![1.00]） |
| AC-P11-4 | 正常 | Given 拖拽缩放 markdown 图片，Then 落盘保留缩放比例且不占用 alt                            |

## 3. 非功能要求

- **数据安全**：写盘原子性（临时文件+重命名）；重名覆盖对齐 Typora（覆盖前无改名——把关时确认是否需要保护）
- **性能**：多图并发 onUpload（Promise.all 单图独立）；本地图片显示经 proxyDomURL + convertFileSrc + assetProtocol scope + CSP img-src 配置

## 4. 测试策略

- **Rust 单测**（核心 100%）：save_image（文件名生成/sanitize/冲突覆盖/原子写/mime 映射）、escape() 等价算法、pathdiff 跨盘符降级、delete_image 回收站
- **前端 Vitest**：粘贴分流（截图/文件复制/HTML 图片/data URL 还原）、onUpload 三路收敛、src 策略组合（相对/./ /转义/绝对）
- **E2E**：粘贴截图存盘、Delete Image 确认链路（本地 CDP/WebDriver）
- **CI**：cargo test + Vitest 全绿

## 5. 依赖与接口

- **消费**：
  - 01：ImageBlock/ImageInline 的 onUpload 注入点、**image-block schema 定制（parseMarkdown/toMarkdown 保 alt）**
  - 02：Rust 写盘 command 习惯（原子写）、C3 编码
- **提供**：
  - Rust command：`save_image(bytes, name, target_dir) -> 相对 src`、`delete_image(path)`（trash 回收站）、`resolve_image_path(src, doc_dir, root_url)`
  - 图片右键菜单（Delete Image 入口）
  - 设置项读取（三开关 + copy-to-folder 目标，与 10 设置模块联动）
- **前端↔Rust 边界**：图片字节经 IPC 传 Rust 写盘；显示经 convertFileSrc + asset protocol
