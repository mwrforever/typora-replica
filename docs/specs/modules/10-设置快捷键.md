## 1. 模块定位与边界

**做什么**：偏好设置面板（7 分区 + 面板内 Ctrl+F 搜索）、双层设置持久化（面板 GUI store + conf.user.json 高级设置）、keyBinding 自定义快捷键（重启生效）、菜单快捷键展示。

**不做什么**：

- 字数统计逻辑与状态栏 UI（11 状态栏；本模块只含 Reading Speed 设置项）
- 菜单栏装配（12）
- 各设置项的**生效实现**（各功能模块负责消费设置值；本模块只管存取与面板）

## 2. 功能点细化（验收标准驱动）

### S1 偏好面板

- 行为：分区顺序 General（含 Save & Recover 内部区）→ Editor → Image → Appearance → Markdown → Export；面板内 Ctrl+F 搜索设置项；云上传相关项禁用占位；重启生效类设置 UI 标注；设置项全集见全量 spec 12.1-12.7（默认值以各调研回填为准）

| 编号    | 类型 | 验收标准                                                                     |
| ------- | ---- | ---------------------------------------------------------------------------- |
| AC-S1-1 | 正常 | Given 打开偏好设置，Then 显示 7 分区导航（General 含 Save & Recover 内部区） |
| AC-S1-2 | 正常 | Given 面板内按 Ctrl+F 输入关键词，Then 过滤出匹配设置项                      |
| AC-S1-3 | 正常 | Given 修改任一设置项，Then 值持久化且重启后保留                              |
| AC-S1-4 | 边界 | Given 云上传相关设置项，Then 显示禁用占位状态                                |
| AC-S1-5 | 边界 | Given 需重启生效的设置项，Then UI 标注「重启生效」                           |

### S2 高级配置 conf.user.json

- 行为：文件名 **conf.user.json**（用户实测裁决）；JSON 支持 `//` 注释（官方明文）；**双层设置**——面板 GUI 走 tauri-plugin-store，高级键走 conf.user.json「注释剥离解析 + 行级键值合并写回」（写回保留用户注释与格式）；键清单：defaultFontFamily/autoHideMenuBar（true 启用）/searchService/monocolorEmoji/flags/autoSaveTimer/keyBinding；Reset Advanced Settings 重置

| 编号    | 类型 | 验收标准                                                                   |
| ------- | ---- | -------------------------------------------------------------------------- |
| AC-S2-1 | 正常 | Given conf.user.json 含 `// 注释` 与键值，Then 正确解析（注释不破坏 JSON） |
| AC-S2-2 | 正常 | Given 修改一个高级键，Then 写回只替换目标行、用户注释与其余格式保留        |
| AC-S2-3 | 边界 | Given 执行 Reset Advanced Settings，Then 高级配置恢复默认                  |
| AC-S2-4 | 异常 | Given 非法 JSON 值，Then 报错且不破坏原文件（保留原样）                    |

### C1 快捷键体系

- 行为：菜单项右侧显示快捷键；**keyBinding 自定义**（键=菜单命令名、值=快捷键组合字符串；重启生效——启动时读 keyBinding 在 01 keymap 注册表 create() 前合并注入）

| 编号    | 类型 | 验收标准                                                                                  |
| ------- | ---- | ----------------------------------------------------------------------------------------- |
| AC-C1-1 | 正常 | Given 菜单项，Then 右侧显示对应快捷键                                                     |
| AC-C1-2 | 正常 | Given conf.user.json 配置 `"Always on Top": "Ctrl+Shift+P"`，When 重启，Then 新快捷键生效 |
| AC-C1-3 | 边界 | Given keyBinding 与内置快捷键冲突，Then 自定义优先（keymap priority 规则）                |
| AC-C1-4 | 异常 | Given 非法快捷键组合字符串，Then 忽略并告警不崩溃                                         |

## 3. 非功能要求

- **持久化安全**：写回原子性；注释剥离跳过字符串内 `//` 边界
- **一致性**：设置快照是各模块读取设置值的唯一入口（合并两文件为单一设置 store）

## 4. 测试策略

- **Rust 单测**（核心 100%）：注释剥离解析、行级合并写回、非法 JSON 保护、Reset
- **前端 Vitest**：面板分区渲染、Ctrl+F 过滤、设置 store 快照合并、keyBinding 解析与注入
- **E2E**：面板开合、设置持久化跨重启（本地 CDP/WebDriver）
- **CI**：cargo test + Vitest 全绿

## 5. 依赖与接口

- **消费**：01（keymap 注册表注入）、02（store 插件约定）
- **提供**：
  - `settingsStore`（Pinia）：全部设置值快照（即时/重启生效两类标注）
  - Rust command：`read_advanced_settings()`、`write_advanced_settings(key, value)`、`reset_advanced_settings()`
  - keyBinding 注入服务（启动时调 01）
- **前端↔Rust 边界**：面板 GUI 走 store 插件；conf.user.json 走 Rust 行级合并
