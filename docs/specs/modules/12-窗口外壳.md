## 1. 模块定位与边界

**做什么**：应用窗口的装配器——Tauri 原生菜单栏（全部菜单项）、侧栏容器（03/05/06 三面板）、中央区（04 标签条 + 01 编辑器/源码模式切换层）、状态栏容器（11）、窗口控制（全屏/缩放/置顶/新窗口/退出拦截）、源码模式切换层、Focus/Typewriter 模式。

**不做什么**：

- 各面板/编辑器/状态栏的内部逻辑（各模块自持，12 只装配容器与转发命令）
- 文件树内拖拽等延后功能
- 跨窗口状态同步（首版不做）

## 2. 功能点细化（验收标准驱动）

### 菜单栏装配

- 行为：File/Edit/Paragraph/Format/View/Themes/Help 全菜单 + Export 子菜单 + Print（11.1-11.7 全表）；**菜单项一律不设原生 accelerator**（防 OS 层抢键，快捷键全部走前端 01 keymap 注册表 + 窗口级 keydown）；菜单 label 文本显示快捷键（"Strong\tCtrl+B"）；菜单 action 与快捷键触发同一命令函数；Themes/Open Recent 动态子菜单运行时重建；autoHideMenuBar（true 启用）+ Alt 单按切换显隐

| 编号   | 类型 | 验收标准                                                                           |
| ------ | ---- | ---------------------------------------------------------------------------------- |
| AC-M-1 | 正常 | Given 打开应用，Then 菜单栏显示 File/Edit/Paragraph/Format/View/Themes/Help 七菜单 |
| AC-M-2 | 正常 | Given 菜单项右侧显示对应快捷键文本                                                 |
| AC-M-3 | 正常 | Given 点击菜单项与按快捷键，Then 触发同一命令（行为一致）                          |
| AC-M-4 | 正常 | Given 安装新主题，Then Themes 菜单动态更新                                         |
| AC-M-5 | 边界 | Given 开启 autoHideMenuBar，When 按 Alt 单键，Then 菜单栏显隐切换                  |

### 源码模式（Ctrl+/）

- 行为：所见即所得（hybrid editing mode）↔ 源码模式双向切换；**切换恢复光标位置**（官方 0.9.90 验收行为）；源码模式有 markdown 语法高亮（CodeMirror 6）；实现 = Crepe 与源码层双实例保活 + v-show 切换（保留 undo 与光标）；文本偏移 ↔ PM 位置映射（MVP：往返切换光标落在同一行/字符附近）

| 编号   | 类型 | 验收标准                                                                  |
| ------ | ---- | ------------------------------------------------------------------------- |
| AC-M-6 | 正常 | Given 按 Ctrl+/，Then 切换到源码模式显示 markdown 源码（语法高亮）        |
| AC-M-7 | 正常 | Given 再按 Ctrl+/，Then 切回所见即所得且光标落在原位置附近（同一行/字符） |
| AC-M-8 | 正常 | Given 源码模式编辑后切回，Then 内容同步回编辑器                           |
| AC-M-9 | 边界 | Given 源码模式下 Focus 模式生效（可叠加，官方证据）                       |

### Focus（F8）/ Typewriter（F9）

- 行为：Focus 淡化非当前行/块，**DOM 契约类名同名实现**（on-focus-mode/md-focus/md-focus-container/md-end-block/--blur-text-color，复用 Typora 主题 CSS）；Typewriter 输入时滚动保持光标居中，**默认鼠标点击也居中**（偏好可关，设置项在偏好面板）

| 编号    | 类型 | 验收标准                                                           |
| ------- | ---- | ------------------------------------------------------------------ |
| AC-M-10 | 正常 | Given 按 F8，Then 当前行/块外内容淡化（on-focus-mode 类生效）      |
| AC-M-11 | 正常 | Given 按 F9，When 输入文字，Then 文档滚动保持光标屏幕居中          |
| AC-M-12 | 边界 | Given F9 模式下鼠标点击其他位置，Then 默认也滚动居中（偏好开启时） |

### 窗口控制

- 行为：F11 全屏（**进入全屏自动隐藏菜单栏**，退出恢复）；缩放 Ctrl+Shift+0/=/-(**范围自定 50%-200%**，WebView 整窗缩放含侧栏，关闭 zoomHotkeys)；Always on Top 菜单项（无默认快捷键，仅当前窗口）；New Window Ctrl+Shift+N（**初始空文档**，各窗口独立 Pinia）；**重启恢复窗口全屏/最大化状态**（window-state 插件）

| 编号    | 类型 | 验收标准                                                                  |
| ------- | ---- | ------------------------------------------------------------------------- |
| AC-M-13 | 正常 | Given 按 F11，Then 全屏且菜单栏自动隐藏；退出全屏恢复                     |
| AC-M-14 | 正常 | Given 按 Ctrl+Shift+=，Then 整个界面放大一档（含侧栏）；范围限制 50%-200% |
| AC-M-15 | 正常 | Given 开启 Always on Top，Then 窗口保持置顶（仅当前窗口）                 |
| AC-M-16 | 正常 | Given 按 Ctrl+Shift+N，Then 新窗口打开（空文档，独立标签状态）            |
| AC-M-17 | 边界 | Given 全屏状态退出应用再启动，Then 恢复全屏状态                           |

### C2 退出聚合确认

- 行为：onCloseRequested 拦截 → 聚合脏标签 → **列表式一次性确认**（全部保存/全部不保存/取消，自定拍板）→ 逐标签写盘（02）→ destroy()（**必须 destroy 而非 close 防死循环**）；无脏标签直接放行；弹窗期间暂停自动保存定时器；关闭最后窗口即退出（Tauri 默认）

| 编号    | 类型 | 验收标准                                                          |
| ------- | ---- | ----------------------------------------------------------------- |
| AC-M-18 | 正常 | Given 多个脏标签时关闭窗口，Then 弹出列表式确认（列出全部脏文件） |
| AC-M-19 | 正常 | Given 选「全部保存」，Then 全部写盘成功后窗口关闭                 |
| AC-M-20 | 边界 | Given 选「取消」，Then 窗口保持打开内容不变                       |
| AC-M-21 | 边界 | Given 无脏标签关闭窗口，Then 直接关闭不弹窗                       |

### 布局装配

- 行为：左侧栏容器（三面板 v-show 切换，宽度可拖拽并持久化）+ 中央区（标签条 + 编辑器/源码层）+ 状态栏容器；消费各模块 store

| 编号    | 类型 | 验收标准                                                        |
| ------- | ---- | --------------------------------------------------------------- |
| AC-M-22 | 正常 | Given 按 Ctrl+Shift+L，Then 侧栏开合；Ctrl+Shift+1/2/3 面板切换 |
| AC-M-23 | 边界 | Given 拖拽侧栏宽度，Then 宽度持久化（重启恢复）                 |

## 3. 非功能要求

- **一致性**：菜单 action 与快捷键单一执行路径（同一命令函数）；窗口级快捷键（Ctrl+W/Ctrl+Tab/Ctrl+Shift+T 等）统一在前端注册，与 01 编辑器 keymap 边界清晰
- **性能**：源码模式双实例保活内存可控（复用 04 LRU 机制）；缩放用 WebView setZoom 零前端成本

## 4. 测试策略

- **前端 Vitest**（核心 100%）：菜单-命令路由表（每个菜单项 → 命令函数映射）、退出聚合状态机、源码模式双向同步逻辑（文本偏移↔位置映射纯函数）
- **组件测试**：布局骨架渲染、Focus 类名注入
- **E2E**：全屏/缩放/置顶/新窗口、源码模式往返切换、退出确认（本地 CDP/WebDriver + Tauri 窗口）
- **CI**：Vitest 全绿 + Rust 窗口 command 单测

## 5. 依赖与接口

- **消费**（全部 01-11 对外接口）：编辑器实例管理（01）、useTabsStore 聚合脏状态（04）、三面板 store（03/05/06）、设置 store（10）、StatusBar.vue（11）、导出服务（09）、主题列表（08）、保存命令（02）
- **提供**：
  - `menuRouter`（菜单项 id → 命令函数路由表，快捷键与菜单共用）
  - 窗口控制 command（Rust）：全屏/置顶/缩放/新窗口/关闭拦截
  - 侧栏容器组件（插槽装配）
- **前端↔Rust 边界**：Tauri Menu API（无原生 accelerator）、window-state 插件、onCloseRequested
